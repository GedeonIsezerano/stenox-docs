A profile combines a speech provider, model, language, filler-removal setting, and optional Polish configuration. Use separate profiles when your language or writing needs change between apps.

## Default and custom profiles

**Default** reflects the app's current settings. It is not a separate stored preset that you can delete. Custom profiles save their own choices, including provider/model, language, whether Polish is enabled, and supported instructions.

Open **Profiles** to create or edit a profile. Pick a profile manually when you want it to stay selected. Choose automatic mode when you want matching trigger rules to select it for you.

## What a profile changes

| Setting | Effect |
| --- | --- |
| Speech provider, model, language | How audio becomes text. |
| Remove filler words | Applies deterministic filler removal independently of AI. |
| Polish settings | Chooses the provider/model and applicable instructions for an explicit Polish action. |
| Trigger rules | Match an app bundle ID or a browser window-title keyword in automatic mode. |

Profiles do not make AI cleanup automatic. Stenox delivers dictation first, then you choose **Polish**. Fixed-purpose models such as S1-mini have their own instruction limits.

Notetaker follows the active speech selection, including a profile. Its insight provider remains separate. Changing a speech model is guarded while a meeting is using it.
