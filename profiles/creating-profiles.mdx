title: "Create a profile"
description: "Save and verify a profile with available speech and cleanup models."
---

<Steps>
  <Step title="Open Profiles">
    Create a new profile and give it a name that describes its purpose, such as English notes or French messages.
  </Step>
  <Step title="Choose speech recognition">
    Select a current provider, model, and supported language. Download local models or configure the provider's API key before relying on the profile.
  </Step>
  <Step title="Choose cleanup">
    Set filler removal independently. Enable optional Polish and select its provider/model if you want an AI action after dictation. Add custom instructions only for models that support them.
  </Step>
  <Step title="Save and try it">
    Choose **Save Profile**, select it, and dictate a short sample. Check the active model and the result before using it for longer work.
  </Step>
</Steps>

## Prepare dependencies

Use **Settings → Models** for downloads and **Settings → API Keys** for supported cloud services. An unavailable provider or missing model is a setup problem, not permission for Stenox to silently send your data somewhere else.

The [provider overview](/providers/overview) lists current choices. Deprecated models may remain visible for migrated selections; use the current catalog for new profiles.

## Add automatic rules

Add an app rule using the app picker, or a window-title keyword for a browser context. Enable automatic profile selection to use the rules. [Automatic selection](/profiles/auto-activation) explains matching and fallback.

Default follows the app's global settings. Edit those settings when you want to change the baseline; use custom profiles for distinct configurations.
