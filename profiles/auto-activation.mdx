---
title: "Automatic profile selection"
description: "Use app and browser-title rules without assuming priority or changing a manual choice."
---

## Turn on automatic mode

Select automatic profile mode when you want Stenox to match the active app. Selecting a profile manually keeps that choice in effect until you return to automatic mode.

## Rule types

| Rule | Matching behavior |
| --- | --- |
| App Bundle ID | Exact match to the active app's identifier. Use the app picker to avoid guessing it. |
| Window Title Keyword | Case-insensitive substring match against the detected browser window title. |

A title keyword is not a URL rule, regular expression, or proof of which website is open. It depends on the title available to Stenox and Accessibility access. Avoid broad keywords that match unrelated tabs.

Profiles are checked in their existing order and the first eligible match wins. Any matching rule can select its profile; app rules do not have a separate guaranteed priority over title rules. If nothing eligible matches, Stenox falls back to Default.

## Verify your rules

1. Prepare the profile's selected models or provider keys.
2. Enable automatic mode.
3. Switch to the target app or browser tab and check the active profile.
4. Switch to an unrelated app and check that the expected fallback is selected.
5. Record a short sample before relying on the setup.

If an unexpected profile wins, narrow overlapping rules. If no profile activates, check that automatic mode is on, the model is available, the app identifier matches, and the browser title contains your keyword.
