## Which build do these docs describe?

These guides follow the app's development **main** branch, reviewed on **October 1, 2026**. They cover current dictation, models, and Notetaker implementation. This is not a claim that a compatible public binary has been released.

The existing public free build remains a separate download. Its screens and feature set can differ from these guides. Use the [download page](https://stenox.app/download) for the build actually available, and check its release notes rather than assuming every documented development feature is included.

## Planned paid release

The website's staged offer is **C$69 once** for early adopters, with a **planned C$100 standard price**, plus applicable taxes. The offer covers two Macs and permanent access to purchased features; future major upgrades may cost extra. Optional third-party provider usage is separate.

<Warning>
  Paid checkout is not open as part of this documentation preview. A price shown on a development website is not a live purchase offer or proof that a compatible paid app is available.
</Warning>

The planned release describes a seven-day full-app trial started online in a compatible app, with no account or card. It is not an ongoing free tier. Paid licensing is planned around weekly verification and up to 30 days offline from the last successful check. Do not use these planned terms as setup instructions for an older public build.

Current purchase, activation, trial, and refund terms belong on the [Stenox website](https://stenox.app). Previously distributed free builds and earlier purchases are separate from the upcoming offer; this page does not replace their terms.

## Local processing and account access

Local model inference does not require an API key after model download. Cloud transcription and Gemini cleanup use your own provider keys. Notetaker subscription insights use an eligible connected account, with that provider's usage limits. App access and provider billing are separate.
