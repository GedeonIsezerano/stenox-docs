Local-first describes a processing choice, not a promise that every feature is offline. Configure speech, Polish, and Notetaker insights separately.

| Feature choice | Processing and data flow |
| --- | --- |
| Parakeet, Whisper, Cohere Transcribe | Audio is processed on your Mac after model download. |
| Local Polish | Dictated text is processed by the selected local MLX model. |
| On-device meeting insights | Conversation, a Personal notes excerpt, and included calendar/reference context are processed locally with Qwen 3.5 4B. |
| Cloud speech | Audio is sent to the selected speech provider. |
| Gemini Polish | Text and the configured writing instructions are sent to Gemini. |
| Subscription insights, refinement / Ask | The selected Codex, Claude Code, or Google Antigravity integration receives the [inputs for that operation](/meetings/processing#context-and-failures), which can include Google-derived information. |
| Google Calendar | Read-only event access uses the connected Google account. Included context follows the selected local or cloud insights provider. |
| V2 trial and paid activation | Online requests verify app access and the device; they do not upload audio, transcripts, or notes. |

## Set up local processing

Choose a local speech provider, choose **Local** for any enabled Polish, and choose **On-device** for Notetaker insights. Download required models while online, then verify they are ready before relying on offline inference. A profile can override speech or cleanup choices, so inspect the active profile too.

Personal notes and preparation questions are included in insight and refinement requests to the selected provider. Long notes use a bounded excerpt; the full saved note stays on your Mac. Ask does not add that field directly, but continued provider context may retain it from earlier turns. See the [operation inputs](/meetings/processing#context-and-failures).

Removing Personal notes, excluding a reference, disconnecting Calendar, removing an event, or switching back to On-device cannot retract earlier cloud submissions. Saved titles, outcomes, and other session content may retain derived information.

Turning **Automatic insights** off stops scheduled reviews; **Generate insights** still uses the selected provider when you choose it. Switching providers does not sign out their accounts. See [Calendar context](/meetings/calendar) for Google's events-only permission, fetched fields, and bounded insight context.

## Storage and services

History and sessions are stored locally. **Active SQLite databases are plaintext**, not encrypted by Stenox. Local storage is distinct from your Mac's access controls and disk encryption.

Provider API keys use macOS Keychain. Subscription runtimes own their sign-in credentials. Provider retention, usage, and account policies still apply to cloud processing; opt-out or deletion request flags are not a zero-retention guarantee.

V2 licensing credentials also use Keychain. Starting the trial and activating a license require internet access. Paid access refreshes weekly and can remain offline for up to 30 days from the last successful verification. The trial ends after seven days, without the paid offline allowance.

Downloads, optional integrations, and app services have their own network requirements. Offline local inference is separate from [app access](/pricing/overview). Read the [Stenox privacy policy](https://stenox.app/privacy) for the public policy.
