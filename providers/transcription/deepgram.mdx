Deepgram is an optional cloud speech provider. Add its key in **Settings → API Keys**, then choose **DeepGram** in a speech profile. Audio is sent to Deepgram and your account's limits and charges apply.

## Models offered by this build

| Stenox label | ID |
| --- | --- |
| Flux Multilingual | `flux-general-multi` |
| Flux English | `flux-general-en` |
| Nova 3 | `nova-3` |
| Nova 3 Medical | `nova-3-medical` |

Use a language supported by the selected model. The new default Deepgram choice is Nova 3; saved choices can differ. A specialized model name is not a guarantee of correctness for a particular recording.

## Dictation, files, and meetings

Flux is a streaming choice for dictation. File transcription and meeting audio windows use **Nova 3** when Flux is selected. Nova selections otherwise retain their model and language. Notetaker requests timed speaker labels and reconciles them across overlapping windows.

Stenox requests model-improvement opt-out (`mip_opt_out=true`). This is not a promise of zero retention. Check [Deepgram's documentation](https://developers.deepgram.com/docs) and your account settings for current service behavior, model access, and policy.

## If a request fails

Check the key, model access, quota, and connection. Optional cloud speech is not bundled with Stenox app access. Switch to a prepared [local speech provider](/providers/overview) yourself when needed.

## Diarized files

In **Transcribe file**, choose **Speakers & timestamps** to request a timed, speaker-labeled result from this provider. This mode preserves wording and disables cleanup/Polish; TXT, Markdown, JSON, SRT, and VTT exports are available. See [file transcription](/setup/file-transcription) for limits and recovery.
