The provider is now called **OpenAI Transcribe** in Stenox. This page retains its older URL so existing links still work; the current selectable models are not the old Whisper-only catalog.

## Configure speech

Add your OpenAI key under **Settings → API Keys**, then select **OpenAI Transcribe** in a speech profile. Choose a supported language and one of the options exposed by the app:

| Stenox label | App model ID | Use |
| --- | --- | --- |
| GPT Transcribe | `gpt-transcribe` | Transcription after recording. |
| GPT Live Transcribe | `gpt-live-transcribe` | Realtime dictation. |

Files use **GPT Transcribe**, including when the live model is selected. Notetaker uses the adapter's file-transcription behavior and local speaker handling where required.

These are the names configured in the reviewed Stenox build. Your provider account must accept the requested model; the app catalog alone is not proof of account entitlement or successful inference.

## Data and billing

Audio is sent to OpenAI. API usage, quotas, and policies belong to your API account and are separate from a ChatGPT/Codex subscription and from Stenox app access. Check the [OpenAI platform](https://platform.openai.com) for account access and current service details.

OpenAI API keys in Stenox are for speech. The current dictation Polish providers are Local and Gemini. For Codex-backed meeting insights, use the separate [subscription integration](/meetings/processing).
