**Whisper (Local)** runs through WhisperKit on your Mac. The current Stenox app requires Apple Silicon and macOS 15 or later; selecting Whisper does not add Intel support.

## Available models

Sizes below are Stenox's catalog estimates, not runtime memory requirements.

| Model | ID | Estimated download |
| --- | --- | --- |
| Tiny (English) | `tiny.en` | ~75 MB |
| Tiny (Multilingual) | `tiny` | ~75 MB |
| Base (English) | `base.en` | ~145 MB |
| Base (Multilingual) | `base` | ~145 MB |
| Small (English) | `small.en` | ~465 MB |
| Small (Multilingual) | `small` | ~465 MB |
| Medium (English) | `medium.en` | ~1.5 GB |
| Medium (Multilingual) | `medium` | ~1.5 GB |
| Turbo (Multilingual) | `large-v3-v20240930` | ~1.6 GB |
| Large v3 (Multilingual) | `large-v3` | ~3.1 GB |
| Distil Large v3 | `distil-large-v3` | ~1.5 GB |

The `.en` choices are English-only. Choose a multilingual model for other supported languages. Model size alone does not guarantee accuracy for your accent or recording.

## Select and prepare

Open **Profiles**, edit Default or a custom profile, and select **Whisper (Local)**. Choose a model and language, then wait for preparation. Alternatively, pre-download the model in **Settings → Models**. Existing profile choices remain in effect until you change them.

A smaller model needs less disk space and can be useful when comparing resource use. Test it with representative speech before relying on the output. [Manage local models](/setup/models) explains cached versus loaded state.

## Workflow limits

Whisper provides speech recognition. Word replacements and optional filler removal are separate steps; **Polish** is an explicit action after the transcript arrives. Notetaker can reuse the active Whisper model with meeting-local speaker processing. Review attribution and timing when the recognizer does not provide detailed word timings.
