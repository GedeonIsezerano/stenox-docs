---
title: "Move from Groq speech"
description: "Migrate a legacy Groq speech profile to a current Stenox provider."
---

Groq speech is not a selectable provider in the current Stenox build. This route is retained for people following older documentation.

Edit any affected profile and choose a current [speech provider](/providers/overview). For local processing, use Parakeet, Whisper, or Cohere Transcribe. For cloud processing, configure a supported provider key and verify a short recording.

An old stored provider ID is not proof that the provider remains supported. Stenox does not silently choose another cloud service for you. Current options are listed under [Cloud providers](/providers/cloud-byok).
