Stenox has three independent processing choices. A local speech model does not make cloud cleanup or subscription insights local.

| Stage | Local choices | Cloud choices |
| --- | --- | --- |
| Speech recognition | Parakeet, Whisper (WhisperKit), Cohere Transcribe | Deepgram, AssemblyAI, OpenAI Transcribe, Gemini Transcribe |
| Dictation Polish | Local MLX cleanup models | Gemini with your API key |
| Meeting insights, refined notes, Ask Stenox | On-device Qwen 3.5 4B | Codex, Claude Code, Google Antigravity subscription integrations |

## Speech recognition

New installations use **Parakeet v2 (English)**. Speech is selected through the Default profile or a custom profile. Notetaker follows the active speech provider and model, including a profile selection; its quick setup model menu changes that shared selection.

## Optional text cleanup

Stenox inserts the transcript before AI rewriting. Turn on **Polish on demand** in **Text cleanup**, select and prepare a model, then click **Polish** after dictation or file transcription. See the complete [local cleanup catalog](/providers/llm/mlx-local) and [Gemini setup](/providers/llm/google-gemini).

## Meeting models

Notetaker reuses speech recognition but manages speaker separation and insights separately. [Meeting processing](/meetings/processing) explains the additional downloads, subscription setup, and data sent for each operation.

## Model downloads and older settings

[Manage local models](/setup/models) explains downloaded versus loaded state. Retired choices may remain in migrated profiles; they are not recommendations for a new setup. Groq and Stenox-hosted cloud services are not in the current selectable catalog. Choose a listed provider if an older profile is unavailable.
