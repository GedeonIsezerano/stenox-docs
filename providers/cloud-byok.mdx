Bring your own key when you want a supported cloud service. Provider availability in Stenox and your account's entitlement are separate; a configured key does not include free usage or guarantee access to every model.

| Provider | Speech | Dictation Polish |
| --- | --- | --- |
| Deepgram | Yes | No |
| AssemblyAI | Yes | No |
| OpenAI | Yes, OpenAI Transcribe | No |
| Google Gemini | Yes, Gemini Transcribe | Yes |

The current catalog does not offer Groq or Stenox-hosted cloud processing. Choose a listed provider if an older profile references a removed service.

## Configure deliberately

1. Create a key in the provider's own console.
2. Add it under **Settings → API Keys** in Stenox.
3. Choose the provider in your speech profile or Text cleanup settings.
4. Try a short sample and check the provider account for access, limits, and usage.

Speech sends audio. Polish sends text and applicable instructions. A local speech provider with cloud Polish still sends text when you click Polish. See [Privacy and data flow](/providers/local-privacy).

## Recover access to a saved key

If a provider reports a Keychain access error, choose **Allow Keychain access** on its card in **Settings → API Keys**. Confirm the macOS request is for your installed Stenox copy and unlock your login Keychain if requested.

Recovery authorizes the saved item for Stenox and reloads its existing key without replacing or deleting it. Your provider and model choices are preserved. If you deny or cancel, the key stays saved and you can retry from the same card. Add a key again only if none is saved or you intend to replace it. This flow is part of the [V2 recovery guide](/guides/upgrading#recover-provider-and-license-access); that guide also covers licensing and other account recovery.

## Provider accounts and usage

Provider pricing, credits, quotas, regions, and retention can change. Check the provider's current console and documentation; the old fixed credit and per-minute figures are not maintained here. Stenox app access does not pay for those services.

For meeting insights using Codex, Claude Code, or Antigravity, use [Notetaker subscription setup](/meetings/processing). Those are separate from BYOK dictation providers.
