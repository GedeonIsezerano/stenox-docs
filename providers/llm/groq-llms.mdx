title: "Move from Groq cleanup"
description: "Migrate legacy Groq cleanup settings to Local or Gemini."
---

Groq cleanup is not a selectable provider in the current Stenox build. This route is retained for older links.

Open **Text cleanup** or the affected profile and choose **Local** or **Gemini** for optional Polish. Download a local model or configure your Gemini key, then test the explicit **Polish** action after dictation.

See [Local AI cleanup](/providers/llm/mlx-local) and [Gemini cleanup](/providers/llm/google-gemini). Neither an old profile nor an old API key automatically enables a removed provider.
