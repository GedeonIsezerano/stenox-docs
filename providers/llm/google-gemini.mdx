Gemini is the current cloud provider for dictation **Polish**. Add a Gemini API key under **Settings → API Keys**, enable **Polish on demand** in **Text cleanup**, and choose **Gemini**.

## Models configured in this build

- **Gemini 3.5 Flash-Lite** — `gemini-3.5-flash-lite`, the new default Gemini selection.
- **Gemini 3.5 Flash** — `gemini-3.5-flash`.
- **Gemini 3.7 Flash** — `gemini-3.7-flash`.

These labels reflect Stenox's current catalog. Account entitlement and successful inference still depend on the provider. The app does not silently upgrade an unavailable model or include provider usage in its own price.

## Use Polish

Dictate normally and wait for the transcript to be inserted or copied. Click **Polish** to send the text and applicable writing instructions to Gemini. The original remains in History. If the request fails, the dictated text is retained.

A local speech model with Gemini Polish is a mixed setup: speech stays local, but the Polish action sends text to Google. See [Privacy and data flow](/providers/local-privacy).

Gemini speech uses a separate [Gemini Transcribe](/providers/transcription/gemini-transcribe) selection. Meeting insights use [Notetaker's providers](/meetings/processing), not this dictation cleanup menu. Review current quotas, access, and policies in [Google AI Studio](https://aistudio.google.com).
