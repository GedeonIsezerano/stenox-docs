---
title: "Add provider API keys"
description: "Configure keys without confusing API usage, subscriptions, and local processing."
---

Open **Settings → API Keys** and add the key for the supported service you plan to use. Keys are stored in macOS Keychain. Do not paste a key into a profile prompt, Vocabulary entry, support message, or screenshot.

| Service | Used by Stenox for |
| --- | --- |
| Deepgram | Cloud speech |
| AssemblyAI | Cloud speech |
| OpenAI | OpenAI Transcribe speech |
| Gemini | Gemini Transcribe speech and Gemini Polish |

## Select the service

A saved key does not switch your provider. Edit the speech profile for transcription, or enable **Polish on demand** in **Text cleanup** and choose Gemini for rewriting. Confirm the active profile before recording.

If your account rejects a request, check key validity, model access, quota, billing, and network connectivity in that provider's console. Stenox does not silently buy capacity or substitute another cloud provider. Switch to a prepared local model yourself when needed.

## API keys versus subscription sign-in

Codex, Claude Code, and Google Antigravity meeting insights use their subscription integrations in **Settings → Notetaker**. They do not use an OpenAI, Anthropic, or Gemini API key entered here. A consumer browser sign-in alone is not proof that the coding runtime is signed in.
