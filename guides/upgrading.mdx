## Choose when to upgrade

Moving from free V1 to paid V2 is optional. V2 adds the workflows described in these guides and uses a **seven-day full-app trial**, followed by a license for new work. **Valid earlier paid Stenox licenses cover V2 without another purchase**, with original rights and device allowances preserved. Inactive, refunded, revoked, or expired licenses do not qualify; see [Release and access](/pricing/overview).

## Before installing

Finish recordings and let saves complete. Export important history and make a current Mac backup before replacing the app. Keep your license receipt and access to your provider accounts available. Do not remove Stenox's saved data, models, or Keychain items to prepare for the upgrade.

## Update through Stenox

**The built-in updater is the normal upgrade path**. Follow Stenox's update prompt, or choose **Check for Updates...** in its menu when that option is shown. If the update is already downloaded, the menu can show **Restart to Update** instead. A separate manual download is not intended to be necessary for everyone.

If the updater cannot offer or complete the upgrade, use the manual fallback: download V2 from the [Stenox website](https://stenox.app/download), quit Stenox, and install it in **Applications**. Open that installed copy.

After either path, check your history, profiles, shortcuts, input device, and model selections before relying on V2 for a meeting. If something is missing, preserve your backup and [contact support](/support/overview).

## Check permissions again

macOS may ask again after the app's signing identity changes. In **System Settings → Privacy & Security**, check Stenox's access:

| Permission | Needed for |
| --- | --- |
| Microphone | Recording your voice for dictation and meetings. |
| Accessibility | Inserting dictated text into other apps. |
| Screen & System Audio Recording | Capturing the other side of a meeting. |

Grant access to the copy you opened from Applications and reopen it if macOS requests it. If Accessibility still refers to an older copy, remove that Stenox entry and add the installed app again. Follow Apple's [screen and system audio instructions](https://support.apple.com/guide/mac-help/control-access-screen-system-audio-recording-mchld6aa7d23/mac) for that permission. This is separate from activating a license.

## Recognize the publisher

Stenox's business name is **GKI Software Inc., formerly Sophosia Software Inc.** The expected Apple signing name for V2 is **Sophosia Software Inc.**, under Team ID **VWXR46VR26**. macOS can therefore show Sophosia in a security or credential prompt even though the website uses GKI Software Inc.

Use the official download and check which app is requesting access. A matching display name alone is not a reason to approve an unexpected prompt.

## Recover provider and license access

An updated app can need permission to use an existing Keychain item. If Stenox reports that a provider's saved key needs access, open **Settings → API Keys** and choose **Allow Keychain access** for that provider. Confirm the macOS request is for your installed Stenox copy, and unlock your login Keychain if requested. Apple's [Keychain guidance](https://support.apple.com/en-asia/guide/keychain-access/kyca1331/mac) explains why an updated app may ask again.

This action updates access to the saved credential and reloads it without replacing or deleting its value. Your provider and model selections stay in place. If you deny or cancel the request, the saved credential stays unchanged and you can retry the same button later.

For licensing, use **Allow Keychain access** in **Settings → License** when offered. It restores access to the saved device identity and licensing state; it does not start another trial or create a new activation. Once access is restored, review the status shown there.

If no provider key is saved, add it under **Settings → API Keys**. Notetaker subscription accounts use their separate connection controls in **Settings → Notetaker**. If a licensing identity was actually deleted or lost, activation may be needed again; release the old device slot through **Manage purchase and devices** if necessary. Denied access alone is not a reason to delete a credential, start another trial, or release a device slot.

If recovery still fails, check whether another Stenox copy is running and [contact support](/support/overview). Do not erase Keychain or allow every application to read an item. Your paid offline allowance does not recover a missing local credential.

## Review changed models and Polish

V2 inserts the transcript first. **Polish** is a separate action, and optional AI cleanup does not block speech-model readiness. Review **Text cleanup**, even if your older build rewrote dictation automatically.

**Gemma 3n 2B and 4B are no longer supported.** Saved selections for removed local models are normalized to the current default, **Gemma 4 E4B**. Check the selected model and its download before polishing. See [Local AI cleanup](/providers/llm/mlx-local) for the current and remaining legacy choices.
