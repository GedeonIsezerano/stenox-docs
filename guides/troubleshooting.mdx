## V2 asks for a trial or license

V2 requires an active trial or license to start new work. Open **Settings → License** to **Start 7-day trial**, **Activate** an existing key, or **Verify now** for paid access while online. Trial expiry is separate from the 30-day paid offline allowance. Viewing and exporting saved history remains available. See [Release and access](/pricing/overview).

If all device slots are in use, release an old Mac through **Manage purchase and devices**. Valid existing purchased licenses keep their original allowance; if an older key is rejected, contact support before buying again. A temporary network failure does not extend the cached verification deadline.

If the app says **Licensing is not configured**, it cannot start a trial or activate a key. Check that you have the intended build and contact support. Changing API keys or permissions will not configure licensing.

## Permissions or Keychain prompts after upgrading

Check that you opened Stenox from **Applications**. Review Microphone, Accessibility, and Screen & System Audio Recording under **System Settings → Privacy & Security**, and reopen the app if requested. Follow [Upgrading to V2](/guides/upgrading) for the publisher name and older permission entries.

For a Keychain prompt, verify the requesting app before granting access. If your login Keychain is locked, unlock it. Re-enter an inaccessible provider key in **Settings → API Keys** or reconnect the affected Notetaker account. If prompts repeat, check whether another Stenox copy is running and send support the prompt wording with private details removed.

Do not erase Keychain, delete saved history, or allow all applications to access a credential. If a licensing identity was already lost, activate your key again and release the old device slot through **Manage purchase and devices** if necessary.

## Recording does not start

Check that Stenox is running with an active trial or license in V2, your input device is selected under **Microphone**, and Microphone permission is enabled in macOS. Wait for the selected speech provider to be ready. End any active meeting before dictating, or finish dictation before starting a meeting.

A language model is optional for dictation readiness. Do not troubleshoot a disabled Polish model as though it were the speech recognizer.

## A model is downloaded but not ready

Downloaded files and a loaded runtime are separate. Review the status in the relevant model controls and allow preparation to finish. Check internet access for missing files and free storage for the download. If preparation failed, use the offered retry after resolving the error.

Avoid deleting model folders by hand while Stenox is using them. Use [Settings → Models](/setup/models) to manage downloads and read any profile warnings.

## Text does not appear

Enable Accessibility for the installed Stenox app under **System Settings → Privacy & Security → Accessibility**. Put the cursor in an editable field and check whether your output mode copies to the clipboard. Some targets do not permit verified replacement; use Copy or retrieve the text from History.

If you installed a different signed build, check that permission is granted to the app you actually opened. Reopen it when macOS requests that step.

## Polish is unavailable or failed

Enable **Polish on demand** in Text cleanup and prepare the selected model or Gemini key. Polish is an explicit action after transcription. Missing local models are not downloaded implicitly by that action. A failure or cancellation keeps the dictated text.

If the field or clipboard changed, the result may be available to copy rather than safely replace. Fixed cleanup models ignore unsupported custom style controls; see [Local AI cleanup](/providers/llm/mlx-local).

## A meeting has missing or duplicated speech

Confirm both Microphone and Screen & System Audio Recording access. Current meetings capture both sources. Headphones reduce the chance that remote voices also enter the microphone. Check the active speech language and input signal.

Speaker separation is not echo cancellation. Overlap and background noise can affect words and attribution. [Edit or reassign passages](/meetings/conversation) rather than assuming the labels identify people automatically.

## Insights or Ask stopped updating

Check the selected Notetaker provider, model, account, and reasoning choice. Account errors, limits, or timeouts can pause automatic reviews until explicit retry. Recording and saved text continue when optional insights fail.

A very short session may not yet have enough contributions. For Google-linked context, use On-device insights. Reference import supports readable text, not OCR of scanned pages. Check the coverage label for partial reference or conversation input.

## A saved session looks incomplete

Review the session's completion or interruption status. A recovered paused session cannot resume recording after the app restarts. Refinement failure does not erase accepted Current insights; export those if a refined draft is unavailable.

Personal notes, references, and Ask history are not bundled in the transcript exports. See [Export and keep your session](/meetings/exports).

If the problem persists, [send feedback](/support/feedback) with your app version, macOS version, selected provider/model, and the visible error. Remove keys and private content from any example.
