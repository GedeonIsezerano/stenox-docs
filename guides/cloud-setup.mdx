---
title: "Set up cloud processing"
description: "Choose cloud features intentionally and verify a short sample."
---

1. Decide which job you want to run remotely: speech, optional dictation Polish, or meeting insights.
2. For speech or Gemini Polish, add the provider key in **Settings → API Keys** and select it in the relevant profile or Text cleanup controls.
3. For subscription meeting insights, connect the provider in **Settings → Notetaker** and choose a runtime-supported model and reasoning setting.
4. Try a short sample and check output, account access, quota, and usage before a longer session.

Cloud speech sends audio; cloud cleanup and insights send required text and context. Provider usage is separate from Stenox app access. Do not rely on historical free-credit or pricing figures from older guides.

A local speech + cloud insight setup still sends meeting text. Google Calendar context requires on-device insights, even if a cloud provider is otherwise connected.

If a service is unavailable, the app does not silently move the job to another account. Notetaker preserves capture and saved text when optional insight generation fails; inspect the error and explicitly retry or change the provider.

See [supported BYOK services](/providers/cloud-byok), [meeting providers](/meetings/processing), and [troubleshooting](/guides/troubleshooting).
