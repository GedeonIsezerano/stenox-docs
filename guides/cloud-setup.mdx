## Local first, cloud optional

Stenox defaults to local Parakeet transcription and Gemma language processing. You only need this guide if you prefer a supported third-party provider.

<Warning>
  Stenox Cloud has been retired. There is no managed Stenox provider, credit balance, subscription, or license-based cloud access.
</Warning>

## How BYOK works

Bring your own key (BYOK) means:

- You create and manage the provider account
- Your key is stored in the macOS Keychain
- Requests go directly from Stenox to the selected provider
- The provider's quotas, prices, privacy policy, and terms apply
- Stenox does not include or resell provider usage

## Configure a provider

<Steps>
  <Step title="Choose a provider">
    Review the [provider overview](/providers/overview) and the provider's current documentation.
  </Step>
  <Step title="Create an API key">
    Sign in to the provider's official console and create a key for your account.
  </Step>
  <Step title="Add the key in Stenox">
    Open Settings, select the transcription or language provider, paste the key, and save it.
  </Step>
  <Step title="Validate before relying on it">
    Use Stenox's provider validation and make a short test dictation. If validation fails, check the key, account quota, and selected model.
  </Step>
</Steps>

## Common combinations

| Goal | Transcription | Language processing |
|---|---|---|
| Fully local | Parakeet | Gemma on MLX |
| Fast cloud | Groq Whisper | Groq LLM |
| High-quality cloud | Deepgram | Google Gemini |
| Local audio, cloud enhancement | Parakeet | Google Gemini or Groq |

<Note>
  Provider offerings and quotas change. Check the provider's official documentation for current models, limits, and prices.
</Note>
